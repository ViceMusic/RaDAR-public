RANKING-AWARE DIAGNOSIS AND ADAPTATION REVIEW

RaDAR协议

针对 RaDAR-Bench 数据集，我们将本研究的数据处理、跨来源诊断与有限标签适应评价流程进行系统整理，形成名为 RaDAR（Ranking-aware Diagnosis and Adaptation Review）的工作流协议。该协议将实验安排组织为规范、可复现的工程流程，并基于研究提出推荐的评估方案；其贡献在于工作流与评价方法的系统化，而非新的预测算法。

域内验证与跨来源诊断排序感知的适应评价独立评价与结果解释

DATA CURATION

数据清洗与任务整理

对不同来源采用统一的记录级预处理流程：以 SMILES 表示分子结构，并保留每条记录的原始专利来源标识。

结构有效性筛选

去除空缺或无效的 SMILES，以及非单体记录。

测量记录保留

保留至少具有一个可用 SIF 或 SGF 稳定性测量值的记录。

按任务独立处理

分别处理 SIF 和 SGF 终点，统一稳定性标签，形成各任务的评价数据。

EVALUATION INPUTS

协议输入

源域训练模型

在源域数据上训练的预测模型，用于建立域内性能参考并开展跨来源评价。

有限目标域标签

少量带标签的目标域样本，用于选择预测阈值或重新拟合模型。

独立目标测试集

与适应所用标签样本分离的目标域测试集，用于最终性能评价。

IN-DOMAIN VALIDATION AND CROSS-SOURCE DIAGNOSIS

域内验证与跨来源诊断

首先在已观测的来源分布内评价模型，建立任务可学习性与预测性能的参考；随后将源域训练模型应用于不同的目标来源，分别考察分类性能与排序能力。

CLASSIFICATION PERFORMANCE

分类性能

使用 Accuracy 与 F1 评价给定决策阈值下的分类结果，考察跨来源条件下的分类性能变化。

Accuracy · F1
RANKING ABILITY

排序能力

使用 ROC-AUC 与 AUPRC 评价预测分数的排序表现，考察来源变化后保留的排序能力。

ROC-AUC · AUPRC

通过比较不同评价条件下的两类指标，分析分类性能下降是否伴随排序能力退化。

RANKING-AWARE ADAPTATION ASSESSMENT

排序感知的适应评价

基于分类性能与排序能力的区分，在相同目标域标签预算下比较阈值调整与模型重新拟合，并结合跨来源迁移中保留的排序能力分析两种方法的相对收益。

THRESHOLD

阈值调整

利用少量带标签的目标域样本，在源域模型的预测概率上选择使 F1 最大的决策阈值；若存在并列最优值，则选择最小阈值。

源域模型预测概率最大化目标样本 F1应用于独立测试集
保留模型参数与原始稳定性标签定义，仅调整预测决策阈值。
REFIT

模型重新拟合

合并源域训练数据与可用的带标签目标域样本，重新训练预测模型，并在独立目标测试集上评价。

源域训练数据 + 目标标签样本重新训练模型应用于独立测试集
与阈值调整采用相同目标域标签预算，以比较两种适应方法的收益。

INDEPENDENT EVALUATION AND INTERPRETATION

独立评价与结果解释

在独立目标测试集上，以 Accuracy、F1、ROC-AUC 与 AUPRC 评价适应结果。用于适应的带标签目标域样本始终与最终测试集分离。

REFERENCE BASELINE

All-positive 对照

将全部样本预测为正类，作为解释分类结果的参考基线，识别主要由正类占比带来的表观收益。

NEGATIVE-CLASS RECOGNITION

Specificity

报告负类识别率，结合 All-positive 对照，判断性能改善是否伴随有效的负类识别。

JOINT ASSESSMENT

联合分析分类、排序与适应结果

通过多维指标与参考基线，对跨来源预测行为进行结构化评价，并解释有限目标域标签条件下不同适应方式的效果。
